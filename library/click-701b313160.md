## Problem

Shell completion treated a partially typed quoted or escaped argument as raw text rather than interpreting its shell syntax. As a result, quote or escape characters became part of the completion prefix, so valid candidates were not matched or were returned incorrectly.

## Fix shape

Parse the incomplete argument with the same shell-aware tokenization used for complete arguments, then use the resulting token as the completion prefix. Preserve special handling for an empty partial argument.
