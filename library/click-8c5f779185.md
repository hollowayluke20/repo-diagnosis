## Problem

Importing a library crashed in newer hosted runtime environments because environment detection assumed that a particular metadata entry always existed. When another runtime indicator was present but the optional metadata entry was absent, direct access raised a missing-key error during initialization.

## Fix shape

Treat optional environment metadata as absent by default when detecting the runtime, so a missing entry produces a negative detection result instead of an exception.
