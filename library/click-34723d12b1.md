## Problem

An executable discovered through a symbolic link was canonicalized before launch, replacing the link path with the underlying binary's path. Multi-call executables use the invoked filename to select their behavior, so this caused the wrong command mode to run.

## Fix shape

Convert the discovered executable path to a normalized absolute path while preserving its final symbolic-link component, so process invocation retains the alias name that selects the intended behavior.
