## Problem

A credentials lookup treated a structurally present result as valid even when every credential field was empty. An empty fallback entry could therefore produce and return empty authentication data instead of behaving as though no credentials were found.

## Fix shape

Accept a parsed credential entry only when it exists and contains at least one non-empty value; otherwise ignore it as absent.
